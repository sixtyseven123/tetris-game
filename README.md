# 俄罗斯方块游戏 (Tetris Game)

一款经典的俄罗斯方块游戏，基于 HTML5 Canvas 和原生 JavaScript 开发，支持多种功能扩展和视觉效果。

## 🎮 游戏特性

### 核心玩法
- 经典俄罗斯方块玩法
- 支持多种难度级别（简单/普通/困难）
- 可调节游戏网格大小（10×20 / 12×22）
- 实时分数、等级、消除行数显示
- 游戏计时功能

### 排行榜系统
- 支持记录玩家昵称、游戏分数、通关时间
- 按分数降序排序
- 按通关时间升序排序
- 清空排行榜功能

### 成就系统
- **初次体验** - 完成第一场游戏
- **满分挑战** - 单局游戏达到5000分
- **速度之王** - 在困难模式下存活超过60秒
- **消行大师** - 单局游戏消除50行
- **俄罗斯方块** - 完成一次四行消除
- **连胜达人** - 连续3局得分超过1000

### 分享功能
- 成绩截图生成（包含玩家昵称、分数、通关时间）
- 分享文本自动生成
- 一键复制到剪贴板

### 视觉效果
- 深色/浅色主题切换
- 精美的加载动画
- 过场动画效果
- 成就解锁通知
- 流畅的方块动画

### 用户体验
- 首次进入游戏操作引导
- 可关闭引导并保存状态
- 移动端触控支持
- 响应式布局设计

## 🕹️ 操作说明

### 键盘操作
| 按键 | 功能 |
|------|------|
| ← → | 左右移动 |
| ↓ | 加速下落 |
| ↑ | 旋转方块 |
| 空格 | 直接落下 |
| P | 暂停/继续 |

### 移动端操作
- 点击屏幕按钮进行控制
- 支持触控操作

## 🚀 快速开始

### 在线体验
打开浏览器访问游戏页面即可开始游玩。

### 本地运行
```bash
# 克隆仓库
git clone https://github.com/sixtyseven123/tetris-game.git

# 进入项目目录
cd tetris-game

# 使用 Python 启动本地服务器
python -m http.server 8000

# 打开浏览器访问 http://localhost:8000
```

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计与动画
- **JavaScript ES6+** - 游戏逻辑
- **Canvas API** - 游戏渲染
- **Web Audio API** - 音效处理
- **LocalStorage** - 数据持久化

## 📱 兼容性

- 支持移动端触控操作
